## Cross-cutting risks

1. **Reviewer access.** Transparency queries remain queryWithAuth by decision (#332); the walkthrough video carries the evidence, so it is now on the critical path.
2. **Capacity release is one-sided.** Cover reserves capacity in production; nothing releases it. A dispute reversal after cover leaves the cents reserved and the exposure figure understated until the receivable ledger lands. Say so in the metric definition doc.
3. **`apps/fund` is fully mocked** (`apps/fund/src/components/investor/transparency-page.tsx` literals) and unauthenticated. Keep it out of every evidence artifact.
4. **SOW internal inconsistency.** The out-of-scope section states twice that the CNPJ is a deliverable of this sprint; section 4.1 lists only the three technical deliverables. Correct the document before submission.
5. **SOW wording drift.** Horizon + `G...` address in the SOW vs Soroban RPC + `C...` contract id in the build (the pulse vault `CA26WJGO…` after #332). Amend the SOW, not the code.
6. **Marketing promise ahead of product.** `mutav#196` ships a site panel promising a real-time coverage ratio readable on Stellar; the coverage ratio is not computed yet.

Resolved since the first audit: the rotting `feat/52-delinquencies-backend` (PR #246 closed, capacity consumption reimplemented in `transitions.ts`) and the lost `worktree-guarantee-lifecycle` state machine (recovered into #316).
